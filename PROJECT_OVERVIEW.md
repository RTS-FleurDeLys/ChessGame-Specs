# CHESS GAME

The goal of this project is to develop a board game engine with the goal of creating a game of chess. Although chess will be the primary game of this project. It is important that the engine remains modular and generic in such a way that makes the addition of new features as easy and sreamlined as possible. 

This project will be developped in three major stages. Each stage will also represent a usable MVP.

# CONSOLE CHESS GAME

The first stage's main end goal is to have a functionnal console app in witch you can play a full game of chess. 

This stage will include the implementation of all the major game systems within the engine. All of these systems will constitute the foundations of the two next stages.

# GRAPHIC APP  

This stage's main end goal is to have a functionnal graphic app in witch you can play a full game of chess.

This stage will use the same core engine systems that will be used by the console app but will simply display the game in a graphic app. This graphic app will include some basic game qol features such as an option menu, menu for creating a game, and basic mouse interactions with the board. 

# SURVIVAL CHESS

This stage's main end goal is to have a functionnal prototype of a new board game called survival chess.

## BRAINSTORM

### ECONOMIC LAYER

The concept of this idea is basically to add an economy. Instead of starting with the classic chess formation, the player starts with a king piece and must build his kingdom and economy. With accumulated wealth, they can create new pieces that would help defend the kingdom.

The way this would work is by adding a second layer to the board. This new layer would be a building layer. So a king could move to a new tile and build a farm on the tile witch would grant income for example. He could also create a barracs witch would be where new pieces can be created.

Other buildings could include forteresses or barricades to help defend tiles.

### LAST STAND

This idead stems from the previous one. It is basically to add a special game mode where the player starts with the classic chess piece formation and no ability to create new pieces meaning they have to last as long as possible with the pieces they start with.

### ZOMBIE PIECES

The concept of this idea is rather simple. Pieces that would constitute the waves would be zombie version of existing chess pieces (pawn, rook, knight, etc...)
